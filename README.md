# WiaPonto - Sistema de Controle de Ponto

Sistema de registro e gestão de ponto eletrônico desenvolvido em React (Vite) e integrado ao Supabase e Vercel.

## 🚀 Tecnologias Utilizadas

* **Frontend:** React + Vite
* **Estilização:** Tailwind CSS + Radix UI
* **Banco de Dados & Autenticação:** Supabase
* **Hospedagem & Deploy:** Vercel

## 🛠️ Configuração e Execução Local

### Pré-requisitos
* Node.js instalado (versão 18 ou superior)
* Conta configurada no Supabase
